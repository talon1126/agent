01 / FACTS

事实驱动购物决策

价格、库存、订单等由业务 API 提供。候选商品先补齐实时事实，再做硬过滤与排序；比较和回答使用同一决策快照。

02 / KNOWLEDGE

知识支持解释与判断

RAG 通过持久 MCP stdio 提供选购指南、FAQ 和政策证据。查询扩展、混合检索与 Self-RAG 在知识子系统内完成，引用进入解释与核验。

03 / DECISION

每一步都有明确产物

十个节点从请求开始，依次形成授权上下文、购物目标、执行计划、候选集、事实快照、排序结果和经校验的回答。执行分支由本轮意图与证据决定。
