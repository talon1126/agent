# Agent Trace 与质量指标字典

本文定义 AImodel Agent Trace v2 的持久化契约和 M3 质量指标语义。Trace
用于重建一次请求的决策过程，不用于保存 Prompt、完整工具返回或用户隐私。

## 统一事件字段

每个事件必须包含以下字段：

| 字段 | 说明 |
| --- | --- |
| `trace_id` | 一次聊天请求唯一的顶层 Trace ID |
| `event_id` | Trace 内唯一的事件 ID |
| `event_type` | 受控事件类型 |
| `stage` | 事件所属决策阶段，默认等于事件类型 |
| `status` | `started`、`success`、`error` 或 `skipped` |
| `started_at` | UTC 开始时间 |
| `duration_ms` | 非负执行耗时；旧记录缺失时按 0 读取 |
| `summary` | 经过脱敏和长度限制的结构化摘要 |
| `related_ids` | 可选的 message、候选集、RAG query trace 等稳定 ID |

`summary_payload` 和 `created_at` 是旧查询兼容别名。事件落库前必须结束；异常和
客户端取消会将所有已开始事件关闭为终态。

## 事件类型

| 类型 | 用途 | 允许记录 | 禁止记录 |
| --- | --- | --- | --- |
| `context` | 请求上下文接入 | 字符数、hash、conversation ID | 完整地址、Cookie、Authorization |
| `goal` | 意图和目标识别 | 受控意图、置信度、规则 ID | 完整用户长文本 |
| `plan` | 工具和步骤规划 | 工具名、步骤数、策略版本 | Prompt、工具密钥 |
| `step` | 通用执行步骤 | 步骤名、状态、计数 | 完整外部内容 |
| `tool_call` | 工具调用 | 工具名、耗时、状态、输入输出计数 | 原始参数和完整工具结果 |
| `filter` | 候选过滤 | 候选数量、淘汰数量、候选集 ID | 用户隐私和商品全文 |
| `rank` | 候选排序 | 排序策略、候选稳定 ID、分数摘要 | 未脱敏特征向量 |
| `verify` | 约束和证据校验 | 规则 ID、通过/失败计数 | 完整文档片段 |
| `response` | 最终响应 | message ID、RAG trace ID 数量 | 完整回答正文 |
| `error` | 失败或取消 | 异常类型、稳定原因码 | 堆栈、凭据、未截断异常正文 |

## 脱敏规则

- API Key、Bearer Token、Cookie、密码和密钥值统一替换为 `[REDACTED]`。
- 收货地址和疑似包含详细地址的查询不进入 Trace，只保留查询字符数与 hash。
- 用户文本只允许有界预览；Prompt、网页正文和外部文档只保存字符数与 SHA-256。
- 目标和候选只保存数量、hash、策略版本或稳定 ID。
- Trace 写入失败不得阻断回答，服务必须写应用错误日志并增加进程内失败计数。

## M3 指标

M3 指标的阈值由 `config/agent_quality_gates.yaml` 冻结。评估生产者使用强类型指标
定义补齐目标、分母、窗口和适用里程碑；报告必须携带 `config_version` 与
`config_sha256`，以避免结果与阈值版本错配。默认窗口均为 `rolling_7d`。

| ID | 目标 | 分母 | 适用里程碑 |
| --- | --- | --- | --- |
| M3-01 | 购物任务成功率 | 符合评估条件的购物任务 | M3 |
| M3-02 | 硬约束零违反 | 已评估推荐 | M3 |
| M3-03 | 商品事实准确 | 已核验商品事实声明 | M3 |
| M3-04 | 关键声明证据覆盖 | 关键推荐声明 | M3 |
| M3-05 | 必要澄清召回 | 需要澄清的请求 | M3 |
| M3-06 | 结构化响应有效 | 已完成 Agent 响应 | M3 |
| M3-07 | 未授权工具调用为零 | Agent 工具调用 | M3 |
| M3-08 | 副作用确认完整 | 副作用尝试 | M3 |
| M3-09 | 可恢复故障恢复率 | 可恢复依赖故障 | M3 |
| M3-10 | 完整响应 P95 时延 | 已完成 Agent 响应 | M3 |

同一配置内指标 ID 和检查字段必须唯一。指标不能引用未知里程碑，不能缺失计算
窗口，运行时也不能删除检查、改变比较方向或放宽冻结阈值。需要调整语义时发布新
的 `config_version`，并保留旧报告所引用的配置 hash。
