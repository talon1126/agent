# AGENTS 文档路由

本文件只作为 workflow / agent 协作文档入口，不存储具体业务数据。
具体内容已按一级标题拆分到 `docs/AGENTS/`，并按二级标题拆分为独立 Markdown 文件。

维护规则：新增或修改某个 agent 的业务说明时，只维护对应目录下的具体文档；根 `AGENTS.md` 只维护路由链接。

所有业务代码都要附带中文注释。
